# qt6webtest

## Файлы:
widgetwebwidget.pro - файл конфигурации

main.cpp - точка входа.

mainwindow.h / mainwindow.cpp - основное окно с упакованным в виджет QtWebEngine.

mainwindow.ui — визуальный интерфейс.

resources.qrc — файл ресурсов.

index.html, assets, images - шаблон  подгружаемого сайта.

##Для запуска требуется:
1. Установленные QT 6.x с QtWebEngine
2. Комплект сборки MSVC

Открытие:
1. Установить папку widgetwebwidget
2. Открыть в qt creator файл конфигурации, выбрать комплект MSVC
3. Запустить
